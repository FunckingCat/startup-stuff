# Perfection By Subtraction – The Minimum Feature Set

Статья о том, что минимальный набор функций — не цель, а тактика, и что первую версию
продукта делают не для рынка, а для узкого типа клиента, которого Бланк называет
earlyvangelist. Разобраны признаки такого клиента, роль долгосрочного видения в его
удержании и правило не добавлять функции, пока не найдена повторяемая бизнес-модель.

## Контекст

США, 2010, корпоративные и B2B-продажи. Бланк пишет из опыта американских enterprise-
сделок, где есть развитая практика пилотов, бюджетные циклы и роль внутреннего
чемпиона. Про другие рынки в статье ничего нет, и приписывать ему географию в условиях
тезисов нельзя. Вопрос переносимости — [[перенос-западного-канона-на-рф]].

## Взято

- Минимальный набор функций — тактика, а не продуктовая цель → [[чем-компенсировать-сырой-продукт]]
- Сырость первой версии терпит только клиент, купивший долгосрочное видение → [[чем-компенсировать-сырой-продукт]]
- Функции не добавляют, пока не исчерпан поиск бизнес-модели → [[чем-компенсировать-сырой-продукт]]
- Корпоративному клиенту вместе с минимальной версией дают роадмап на 18–36 месяцев → [[чем-компенсировать-сырой-продукт]]
- Первую версию показывают узкой группе визионеров, большинство её возненавидит → [[как-выбрать-первый-сегмент]]
- Ранний клиент отбирается по уже собранному самодельному костылю → [[как-выбрать-первый-сегмент]]
- Первого клиента берут только с бюджетом → [[как-выбрать-первый-сегмент]]
- В B2B берут внутреннего евангелиста, а не того, кто вправе подписать → [[как-выбрать-первый-сегмент]]

Ещё два кандидата развёрнуты в определения концептов: earlyvangelist как имя того же
профиля раннего клиента → [[профиль-раннего-пользователя]]; повторяемость паттерна
продаж как признак конца поиска → [[повторяемая-бизнес-модель]].

## Слито с существующим

- Продукт ранней стадии формирует горстка конкретных ранних клиентов → блок Пола Грэма на [[чем-компенсировать-сырой-продукт]]
- Ранний клиент осознаёт проблему и ищет решение в срок → блок на [[профиль-раннего-пользователя]]
